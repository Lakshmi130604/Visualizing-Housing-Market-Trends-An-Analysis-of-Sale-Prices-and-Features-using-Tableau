# Visualizing-Housing-Market-Trends-An-Analysis-of-Sale-Prices-and-Features-using-Tableau
📌 Project Overview

This project analyzes housing market trends by visualizing sale prices and key housing features using Tableau. The aim is to understand how different property attributes such as age, renovation status, bedrooms, bathrooms, and floors influence house sale prices. Interactive dashboards help identify pricing patterns, demand segments, and feature-based value differences in the housing market.

🎯 Objectives

To visualize housing sale price trends using interactive dashboards.

To analyze how house features affect property value.

To identify high-demand price segments in the housing market.

To support data-driven decision making in real estate analysis.

🧹 Data Preparation Steps
1. Data Collection

Collected housing dataset containing sale price and property features.

2. Data Cleaning & Transformation

Removed missing and duplicate values.

Converted data types (e.g., Sale Price to numeric).

Created calculated fields:

Price Bins (250K, 300K, etc.)

Years Since Renovation

Average Sale Price

Standardized column names.

3. Data Aggregation & KPI Creation

Calculated key performance indicators:

Total Number of Houses

Average Sale Price

Sum of Age of Houses

Grouped data by:

Price Ranges

Renovation Status

Age Categories

📊 Exploratory Data Analysis (EDA)

The analysis explores relationships between:

House Age vs Sale Price

Renovation Status vs Price

Bedrooms/Bathrooms vs Property Value

Floors vs Age of House

This helps identify patterns influencing housing prices and demand.

📈 Visualizations Developed

The Tableau dashboard includes:

KPI Cards (Total Houses, Average Price, Sum of Age)

Bar Chart – Sales by Price Bins

Pie Chart – Renovation Distribution

Comparative Charts – Bedrooms, Bathrooms, Floors vs Age

Interactive Filters for dynamic exploration

🔍 Key Insights

Renovated houses tend to sell at higher price ranges.

Houses with more bedrooms and bathrooms generally have higher value.

Newer houses often achieve better sale prices than older ones.

Certain price ranges show stronger market demand.
